NotebookLM Extractor
====================

Requirements:
- Windows 10 or Windows 11, 64-bit
- Google Chrome
- Internet connection

Portable use:
1. Extract the entire ZIP file.
2. Run NotebookLMExtractor.exe.
3. The web interface opens at http://127.0.0.1:8765.
4. Sign in to Google in the Chrome window when requested.

User data and generated files are stored in:
%LOCALAPPDATA%\NotebookLMExtractor

Python is not required.
